Raspberry Pi Embedded Motion & Alert System

● zero-lag trigger

A C++ pipeline that reads a PIR sensor over the libgpiod library on a Raspberry Pi 5, then pushes real-time alerts through an ntfy.sh webhook the moment motion is detected. Hardware control logic switches an LED on or off on every state transition, with no lag between sensor and signal.

C++Raspberry Pi 5libgpiodntfy.shHardware interfacing

Real-Time Velocity & Ultrasonic Motion Detector

● <15cm trigger radius

An object-tracking system built around an HC-SR04 ultrasonic sensor and Raspberry Pi 5. I designed a voltage divider circuit to safely step the echo signal down from 5V to 3.3V for the Pi's GPIO pins, then wrote the control logic to track pulse timing precisely and trigger a red LED whenever an object closes within 15cm.

C++Raspberry Pi GPIOHC-SR04Sensor interfacingCircuit design

Ciliafy — Biological Waveform Analysis Framework

● 82% accuracy

An automated image-processing framework in Python and C++ that segments cilia centerlines and tracks motion across an 872-video dataset. I combined Fast Fourier Transform analysis of ciliary beat frequency with physics-based rod models for bending and curvature, then trained SVM, XGBoost, and CNN/RNN classifiers to detect patterns linked to Primary Ciliary Dyskinesia — reaching 82% detection accuracy.

PythonC++OpenCVFFTSVM / XGBoost / CNN-RNN

Environmental Cold-Chain & Cargo Telemetry System

● in progress

A cargo-monitoring system in development that tracks temperature, shock, and impact via BMP280 and MPU6050 sensors wired to an ESP32 over I²C. Sensor data streams to a Raspberry Pi over MQTT, feeding a C++ application that shows real-time updates, fires LED and buzzer alerts on threshold breaches, and timestamps every event.

C++Raspberry PiESP32I²CMQTTBMP280 / MPU6050
